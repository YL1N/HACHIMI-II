# XES 60×96 共测 Harness 实验落地说明（2026-05-07）

## 1. 本次实验设置

这次实验改成固定共测：

- 学生：60名，`poor/low/medium/high` 各15名。
- 测试题：96道共同题，所有学生都测同一批题。
- 历史题：每名学生取30道个人历史题。
- 历史题来源：只从这96道测试题之外取。
- 历史抽取：按学生自己的作答时间序列分成前中后三段，每段取10题。

这不是严格的“先历史、后未来测试”预测。
它是：

> 静态画像构建 + 共同测试。

也就是说，历史只用来建学生画像，96道题只用于统一评测。

## 2. 要跑的三个版本

### 2.1 强模型 harness，带 Hachimi

- `persona_source_mode = xes_history_plus_hachimi`
- 用 XES 历史数学表现增强 Hachimi 学生画像。

### 2.2 强模型 harness，不带 Hachimi

- `persona_source_mode = xes_history_only`
- 只用 XES 历史数学表现构造画像。

### 2.3 弱模型 harness

- 使用同一批60名学生和96道题。
- 默认沿用当前弱模型 harness 的带 Hachimi 学生画像路线。
- 弱模型只在支架预算内作答，不先预测对错。

## 3. 固定配置

固定样本文件：

- `xes/configs/common_test_60x96_20260507.json`

该文件固定：

- 60名学生名单；
- 每名学生所属层级；
- 96道共同测试题；
- 30题历史抽取规则。

## 4. 主指标

最终报告至少给出：

1. 题目正确率 Pearson；
2. 题目正确率 Spearman；
3. 学生总分 Pearson；
4. 一致率；
5. 模型总体正确率。

辅助指标包括：

- 学生总分 Spearman；
- 学生总分 MAE；
- 模型总体正确率和真实总体正确率差值；
- 各层级真实正确率；
- 各层级模拟正确率；
- 各层级一致率。

## 5. 一致率定义

对每个学生，比较96道题上：

- 真实学生这题对/错；
- harness 模拟这题对/错。

然后先算每个学生的一致率，再对60名学生取平均。

因为每个学生都是96道题，所以它和整体逐题 agreement 很接近，但报告里仍单独列出。

## 6. 防作弊边界

生成阶段不能使用：

- 96道测试题的真实对错标签；
- 真实题目正确率；
- 离线评测指标；
- 为贴近结果而后处理改答案。

真实标签只在最后离线评测时进入。

## 7. 输出要求

跑完后需要保存：

- 三个版本各自的 `metrics.json`；
- 三个版本各自的 `predictions.jsonl`；
- 最终 Markdown 报告；
- 至少一个具体 case dump。

case dump 要包含：

- 一个具体学生；
- 一道具体题；
- 学生历史；
- 题目信息；
- harness 中间对象；
- 发送给模型的输入；
- 模型输出；
- 最终判分结果。
