## 6. 这些数字代表什么

### Accuracy

- 它表示“预测对/错标签”的总体命中率。
- 但这个指标单独看不够，因为真实数据里“做对”本来就比较多，模型只要总是偏向“对”，Accuracy 也可能不低。

### Balanced Accuracy 和 MCC

- 这两个指标更看重模型有没有真的分清“哪道题会错、哪个学生会错”。
- 如果模型只是机械地偏向一边，这两个数会很低。
- 所以它们比单看 Accuracy 更能反映模拟是否有区分能力。

### 题目 Pearson / Spearman

- 这是看“真实学生在哪些题上更容易对、哪些题上更容易错”，模拟学生有没有跟上这个题目层结构。
- Pearson 看线性一致性。
- Spearman 看难度排序是否一致。

### Rasch item-b Pearson

- 这是更严格的题目难度结构指标。
- 它不是只看平均正确率，而是看重新拟合 Rasch 以后，模拟题目难度和真实题目难度是否同向。
- 如果这个数接近 0 或者是负数，说明心理测量结构没有保住。

### 学生 Pearson / Spearman

- 这是看模拟学生总体强弱和真实学生总体强弱能不能对齐。
- 如果这个数高，说明模型至少知道“谁大体更强、谁大体更弱”。
- 如果这个数接近 0，说明学生层分布基本塌了。

### 显式失败率

- 这是协议层失败率，比如输出无法解析、格式不合法、状态校验不通过。
- 这个指标高，说明模型连 harness 协议本身都跟不稳。
- 这个指标低，不代表模拟成功，只代表“至少没有大量格式性炸掉”。

## 7. 怎么理解这三组弱模型结果

### 1.7b：最稳，但明显太保守

- 它的显式失败率最低，只有 `1.73%`，说明协议跟随最稳。
- 但它把整体正确率压得太低了，模拟正确率只落在三成多。
- 四档学生顺序也没有保住，甚至出现 `poor > high` 的反转。
- 这说明它不是“像真实学生一样分层作答”，而是“整体偏弱地答”。

### 3b：题目层稍好一点，但学生层更差

- 它的题目 Pearson / Spearman 比 `1.7b` 更高，说明题目层难易感知比 `1.7b` 好一点。
- 但它的学生 Pearson 和 Spearman 都变成负数，说明学生强弱结构不但没保住，还出现反向。
- 同时它的显式失败率升到 `10.58%`，协议稳定性最差。
- 所以 `3b` 不是一个可接受的折中方案。

### 7b：三者里最好，但仍然不够好

- 在三组弱模型里，`7b` 的整体结果最好：
  - Accuracy 最高：`0.4879`
  - 学生 Pearson 最高：`0.1388`
  - Rasch item-b Pearson 也是三者里唯一转正：`0.0853`
- 它也开始恢复一点分层形状：`poor < low < medium`，只是 `high` 还没有真正压过 `medium`。
- 但即便如此，它距离强模型静态基线依然差得很远：
  - 强模型静态基线学生 Pearson 是 `0.3328`
  - `7b` 只有 `0.1388`
  - 强模型静态基线题目 Pearson 是 `0.2314`
  - `7b` 只有 `0.1196`

## 8. 和前三块实验放在一起看，当前该怎么判断

### 第一，formal v2 现在已经是“能稳定全量跑完”的方法

- 这次 `1.7b / 3b / 7b` 三组都完整跑完了。
- 所以现在卡点已经不再是“脚本会不会炸”“协议会不会乱”“能不能续跑”。
- 这部分工程问题，当前算是解决了。

### 第二，当前弱模型 harness 还不是一个成功的实证方案

- 三个弱模型里最好的 `7b`，依然明显弱于现有强模型静态基线。
- 尤其是在“学生层分布”和“题目层结构”这两个核心目标上，还没有达到可接受水平。
- 所以现在不能说“换成弱模型 + harness 就已经能模拟真实学生了”。

### 第三，当前问题已经不是单纯的格式问题

- `1.7b` 失败率很低，但结果依然差。
- 这说明问题不在“它老是输出乱码”。
- 真正的问题是：harness 现在虽然能把协议压稳，但还没有把学生能力边界有效翻译成题目级作答决策。

### 第四，当前更像是“把模型压弱了”，还不是“把模型扶成学生了”

- 1.7b 和 3b 都很明显地把整体正确率压到三成左右。
- 7b 虽然上来一些，但仍远低于真实学生整体水平。
- 这说明当前 harness 更像是在限制能力、收紧输出，
- 还没有真正做到：在不作弊的前提下，让弱模型沿着真实学生分层去作答。

---

## 9. 当前最直接的结论

如果只看现在的证据，最准确的表述是：

> 现有 XES 强模型静态版已经能粗粒度抓住部分学生强弱，但题目级结构仍然有限；formal v2 弱模型 harness 现在已经具备稳定全量运行能力，但在 `1.7b / 3b / 7b` 三组全量实验中，都还没有把弱模型真正扶到“像真实学生一样分层作答”的水平，其中 `7b` 最好，但仍明显不足。
