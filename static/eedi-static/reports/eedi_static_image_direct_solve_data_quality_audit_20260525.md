# EEDI-static 原图错题数据质量审计（2026-05-25）

## 1. 审计对象

本次审计对象是原图直答中模型答错的 58 道题。

目的不是解释模型为什么错，而是检查这些错题里有没有应该从测试集中删除的坏题。

## 2. 审计标准

只把下面情况视为可删除的数据质量问题：

1. 图片损坏、截断、看不清；
2. 题目本身缺信息，单张图无法作答；
3. 官方/训练记录里的正确答案明显冲突；
4. 选项对应关系无法确定；
5. OCR/图片元数据和题号错配。

模型答错本身不作为删题理由。

人工抽看了高风险错题，包括：

- 平行线角度题；
- 代数表达式题；
- 网格倍数题；
- addition pyramid 题；
- 低分辨率点阵题。

这些题都可以从单张图中作答。

目前没有发现：

- 题干缺失；
- 选项缺失；
- 图形被裁掉；
- A/B/C/D 对应关系不可判断；
- 图片和题号明显错配。

## 6. 结论

本轮没有发现需要删除的坏题。

58 道错题更像是模型能力边界题，而不是数据质量问题。

建议：

> 保留当前 265 题测试集，不因为 qwen3.5 原图直答错误而删题。

后续如果要删题，应只基于人工确认的数据质量问题，而不是基于模型是否答对。
